# @cldmv/envm v1.0.12 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A dev-dependency release. The `@cldmv/vitest-runner` test runner moves from 1.2.0 to 1.5.3, and `vitest` and `@vitest/coverage-v8` move from 5.0.2 to 5.0.3. Nothing under `src/` changed, and `package.json` differs from v1.0.11 only in its `version` field: all of it is a lockfile re-resolution inside the existing `^` ranges. Every package that changed in `package-lock.json` is a development dependency, and the package has no runtime dependencies, so the library and CLI are unaffected.

The notable effect is on the toolchain's Node.js floor. `@cldmv/vitest-runner` 1.5.3 declares `engines.node` `>=22.12.0` (it was `>=20.19.0` in 1.2.0) and depends on `chalk` 6, which needs Node.js 22. The CI matrix already starts at 22.12.0, the floor `vitest` 5 runs on, so CI is not affected; running `npm test` locally now needs Node.js 22.12.0 or later. `envm` declares no `engines` field, and that is unchanged.

## 🔧 Dependencies

All development-only; none is a runtime or peer dependency of `envm`.

- `@cldmv/vitest-runner` `^1.2.0` → resolved 1.5.3 ([#44](https://github.com/CLDMV/envm/pull/44)). The `package.json` range stays `^1.2.0`; only the lockfile moved. The jump covers the 1.3 to 1.5 releases, including a real bundled `dist/` build, an `exclude` option for test discovery, and a CommonJS entry that now fails with a clear `ERR_REQUIRE_ESM` message on Node.js without `require(esm)`. Its `engines.node` moves from `>=20.19.0` to `>=22.12.0`. Its `chalk` dependency moves from `^5` to `^6`, so the lockfile's top-level `chalk` goes from 5.6.2 (`engines.node` `^12.17.0 || ^14.13 || >=16.0.0`) to 6.0.1 (`engines.node` `>=22`).
- `vitest` 5.0.2 → 5.0.3 ([#42](https://github.com/CLDMV/envm/pull/42)), with `@vitest/mocker` and `@vitest/spy` at 5.0.3. `vitest` 5.0.3 pins `why-is-node-running` to exactly 3.2.1, so that package resolves one patch version lower than before (3.2.2 → 3.2.1).
- `@vitest/coverage-v8` 5.0.2 → 5.0.3 ([#43](https://github.com/CLDMV/envm/pull/43)).
- Transitive tooling that moved with the Vitest update: `vite` 8.3.1 → 8.3.2, `rolldown` 1.2.11 → 1.2.12 (and its platform bindings) and `@oxc-project/types` 0.151.0 → 0.152.0.

## Upgrade notes

- No breaking changes, and no runtime code changed. It is a drop-in replacement for v1.0.11.
- For contributors: running the test suite locally needs Node.js 22.12.0 or later.
